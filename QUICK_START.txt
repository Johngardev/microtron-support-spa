🚀 INSTALACIÓN RÁPIDA (30 segundos):

Windows:
  $ setup.bat

macOS / Linux:
  $ bash setup.sh

Manual (3 minutos):
  Terminal 1:
    $ cd support-api && npm install && npm run start:dev
  
  Terminal 2:
    $ cd support-web && npm install && npm start

⚙️ CONFIGURACIÓN (.env):

Archivo: support-api/.env

COSMOS_MONGO_CONN=mongodb://your-connection-string
DATABASE_NAME=support
JWT_SECRET=your-secret-key
JWT_EXPIRES_IN=24h
CALENDLY_TOKEN=your-token-here

Obtener token en: https://calendly.com/settings/integrations/api_webhooks

🔌 ENDPOINTS PRINCIPALES:

POST   /sessions              Crear sesión
GET    /sessions              Listar sesiones
GET    /sessions/:id          Obtener sesión
PATCH  /sessions/:id          Actualizar sesión
DELETE /sessions/:id          Eliminar sesión
GET    /sessions/stats        Estadísticas

POST   /sessions/:id/calendly-event    Crear evento Calendly
DELETE /sessions/:id/calendly-event    Cancelar evento
